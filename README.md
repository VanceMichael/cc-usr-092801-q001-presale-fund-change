# 预售资金变更与购房人告知闭环

管理商品住房预售变更、资金节点、购房人告知与责任回放。

## 参与方与事实

主要参与方包括房地产交易监管人员、开发企业、监理单位、购房人、资金监管机构。领域资料记录以下已经确认的事实：

- 上海优化商品住房预售标准
- 建设单位原则上不得擅自变更设计和施工方案
- 涉及已售房源的变化需要依法依规处理

## 业务约束

- 许可证和合同版本
- 工程节点拨付
- 变更告知
- 异议处理
- 时点回放

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/presale_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
